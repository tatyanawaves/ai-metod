# CogniSynapse — Autonomous Self-Learning AI & Knowledge Engine

> **Автономный самообучающийся искусственный интеллект**, способный в реальном времени искать мировые новости, извлекать факты, развивать граф знаний по нескольким методам обучения, синтезировать мультимедиа (изображения и видео через Google Veo / Imagen 3) и отвечать на вопросы по накопленной базе знаний.

---

## 🌟 Основные возможности (Key Features)

1. **Автономный цикл обучения по новостям (Autonomous News Ingestion & Learning Loop)**:
   - По кнопке ИИ самостоятельно выходит в интернет через Google Search Grounding.
   - Находит актуальные события, анализирует первоисточники и вычленяет ключевые сущности, связи и концепции.
   - Возможность в любой момент **поставить обучение на паузу** или возобновить его, а также настраивать интервал шагов (5с / 15с / 30с / 60с) или запускать единичные итерации вручную.

2. **4 метода обучения (Multiple Learning Paradigms)**:
   - 🔍 **Индуктивная дистилляция знаний (Inductive Knowledge Distillation)**: сбор эмпирических фактов из свежих новостей и обобщение их в устойчивые системные выводы.
   - ⚖️ **Диалектический синтез и верификация (Dialectical Synthesis & Verification)**: сопоставление тезиса и антитезиса, проверка фактов и устранение противоречий.
   - 🎨 **Мультимодальное семантическое заземление (Multi-Modal Semantic Grounding)**: увязка текстовых понятий с визуальными образами, анимациями и сенсорными метафорами.
   - 📐 **Дедуктивная интеграция от первых принципов (Deductive First-Principles Integration)**: встраивание новых открытий в фундаментальные законы логики и физики.

3. **Интерактивный граф знаний (Knowledge Graph & Epistemic Memory)**:
   - Визуализация взаимосвязей между сущностями (концепты, технологии, персоны, события).
   - Динамический расчет весов, связей, уверенности (confidence) и уровня зрелости ИИ (Synaptic Level, Memory Items, Total Relations).

4. **Мультимодальная студия (Visual Studio & Imagen 3)**:
   - Автоматическая и ручная генерация иллюстраций для изученных тем.
   - Поддержка Imagen 3 / Gemini Image Generation с отказоустойчивым синтезом векторных high-res SVG полотен при исчерпании квот.

5. **Видеолаборатория Veo (Veo Video Lab)**:
   - Интеграция с передовой видеомоделью **Google Veo 2** (`veo-2.0-generate-001`).
   - Генерация кинематографических видеороликов по текстовым промптам и изученным темам с трекингом статуса и скачиванием MP4.

6. **Когнитивный диалог (Cognitive Q&A)**:
   - Интерактивный чат с ИИ, где ответы генерируются с опорой на накопленный граф знаний и живой интернет-поиск.

## 🛠 Технологический стек (Tech Stack)

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Motion.
- **Backend**: Node.js, Express, TSX.
- **AI Models & SDK**:
  - `@google/genai` (официальный Google Gen AI SDK).
  - `gemini-2.5-flash` / `gemini-3.8-flash` с Google Search Grounding для новостей и рассуждений.
  - `gemini-3.1-flash-lite` в качестве умного резервного шлюза при перегрузках.
  - `veo-2.0-generate-001` для генерации видео.
  - `imagen-3.0-generate-002` для генерации фотореалистичных изображений.
- **Сборщик**: Vite.

## 🚀 Быстрый старт (Quick Start)

### 1. Клонирование репозитория
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd cognisynapse
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корне проекта (на основе `.env.example`):
```env
GEMINI_API_KEY=ваш_ключ_api_из_Google_AI_Studio
PORT=3000
```
> Получить бесплатный API ключ можно в [Google AI Studio](https://aistudio.google.com/apikey).

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Откройте браузер по адресу [http://localhost:3000](http://localhost:3000).

### 5. Сборка для продакшена
```bash
npm run build
npm start
```
